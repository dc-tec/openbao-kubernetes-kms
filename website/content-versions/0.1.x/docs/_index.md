These guides describe **0.1.0-preview.2**, the published preview release.
Use it in disposable evaluation clusters. Read the
[release corrections](/docs/errata/) before installation.

Start with [Getting started](/docs/getting-started/), then select
[systemd](/docs/deployment/systemd/) or a
[static pod](/docs/deployment/static-pod/).

The [CLI reference](/docs/reference/cli/) describes the commands available in
this release. The `init` command and native OAuth client credentials are in
[development documentation](/next/docs/) and are not available in preview.2.
